# Components

Thirteen headless components, each one a small set of parts that share a
context. Behaviour, ARIA wiring and focus management come from the parts;
appearance is entirely yours.

| Component | What it does |
| --- | --- |
| [Accordion](/components/accordion) | Stacked expandable panels, `single` or `multiple` |
| [AlertDialog](/components/alert-dialog) | Modal that requires an explicit decision |
| [AspectRatio](/components/aspect-ratio) | Locks a child to a ratio |
| [Avatar](/components/avatar) | Image with an automatic fallback |
| [Checkbox](/components/checkbox) | Tri-state: checked / unchecked / indeterminate |
| [Collapsible](/components/collapsible) | One expandable region |
| [NumberField](/components/number-field) | Numeric input with steppers and clamping |
| [PinInput](/components/pin-input) | One-time-code entry with paste distribution |
| [Progress](/components/progress) | Determinate or indeterminate progress |
| [Separator](/components/separator) | Horizontal or vertical divider |
| [Switch](/components/switch) | Two-state toggle |
| [Tabs](/components/tabs) | Layered panels, one visible |
| [TagsInput](/components/tags-input) | Tag field with keyboard editing |
